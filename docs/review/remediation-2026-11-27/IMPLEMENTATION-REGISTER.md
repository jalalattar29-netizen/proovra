Additional changes made during verification (2026-11-27):
- The batched second-review read (`secondReviewRequiredForRounds`) now applies exactly the per-workflow rule (disagreement-only ESCALATED, workspace policy, carried cause via the shared `pinnedCauseFromRoundEvents`).
- A later escalation never overwrites the disagreement marker, and a free-text escalation note can never equal it (`escalationNoteForStorage`).
- The second-review re-evaluation reads `requires_independent_review`.
- A Collaboration Team task on a review uses the Review placement rule.
- `viewer.escalationForcesIndependentReview` (always false after the policy change) was removed from the projection.
- A request for information completes the FIRST_REVIEW deadline (it is the reviewer's first substantive response) and is listed in the decision history as `informationRequests`.
