ROOT CAUSES AND DISPOSITIONS

PA-08  STALE FIXTURE — cookie consent. f1d4ba49 (2026-08-30) set `hideFromBots: false` on purpose: hiding the
       consent UI from automation also removed the dialog Settings opens to change one's own consent. From then
       the "Privacy Preferences" box sat over every page in the layout projects (none had a recorded decision),
       took the pointer events meant for the controls under it, and added two role="dialog" elements.
       Fix: playwright.config.ts gives every layout project a recorded-consent cookie (the record the library
       writes; the same one e2e/settings-layout already used). Accounted for ~30 of the 73 (clicks that never
       arrived in search, attention, intake-links, evidence-detail).

PA-04  PRODUCT DEFECT — evidence-detail service-status (2 failures). One artifact-generation incident was stated
       twice on the Artifacts tab when a new-version offer and a package recovery were both available: the
       report panel and the package panel each rendered their own RuntimeStatusBanner. Fix: one function,
       reportPanelStatesGenerationIncident, decides which panel speaks; the report panel owns it, the package
       panel states it only when the report panel does not. Render tests: 5 new cases in
       evidence-artifacts-output-actions.render.test.tsx.

PA-05  PRODUCT DEFECT — billing (2 failures). "Start Team subscription", a purchase, was outlined while the page's
       other purchase entry points (Buy credits, storage) carry `app-secondary-action--filled`; it read as the
       lighter action beside "View access details". Fix: it carries `--filled` (dark ink, white label, dark hover).

PA-06  PRODUCT DEFECT — intake-links table overflow at 1200–1279px. The cutover to cards moved to 1199px
       (67368b23, 2026-09-05) but the short-label fold for the two nowrap columns stayed at max-width 1080px,
       where no table renders any more: at 1200px the seven columns needed 1061px in a 988px frame (a 75px
       sideways scroller), up to 1273px. Fix: the same fold, scoped to the table, for 1200–1279px.

PA-07  PRODUCT DEFECT — intake-links timeline key at a larger text scale. `.ilk-timeline__key` was sized in rem
       while the column's cap is in ch of the cell's own text, so a 20px root pushed the nowrap date 0.5–6px out
       of its cell. Fix: 3.968em (the same 49.6px at the default root).
