PROOVRA Offline Verifier

Bounded, third-party-runnable verification of PROOVRA Verification Packages.

Privacy: Verification runs locally in your browser. The selected ZIP is never uploaded. No data is sent to PROOVRA or any third party. This page works fully offline once loaded (apart from the JSZip dependency below, which can be cached).

Old packages (generated before P3.1.1) verify with bounded missing / unsupported states — they are NOT treated as failed.

Bounded scope.
  • Verifies: checksum integrity, package manifest sanity, presence of detached attestations + signer snapshot, presence of TSA / OTS material.
  • Does NOT: claim legal admissibility, claim authorship, run full RFC3161 TSA verification, run OpenTimestamps Bitcoin verification, or contact PROOVRA's servers.
  • For the cryptographic signature on custody attestations, consult PROOVRA's API (/v1/operations/custody-attestations/:id/verify) — the public material is not bundled inside the package.
